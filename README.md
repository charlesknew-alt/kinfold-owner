# Varlo Owner Portal

Owner dashboard for The Windmill Inn and The Eight Bells.

Lives at [owner.kinfoldinns.co.uk](https://owner.kinfoldinns.co.uk).

Paperwork and Card Takings are Google Apps Scripts iframed with `shell=owner`.
If those tools show **Not authorised**, apply
`apps-script/doGet-owner-gate-patch.gs` in both paperwork scripts and redeploy
the existing web apps. Do not put an owner-paperwork link back on the manager hub.
