Menus — quick guide

For the floor · one sheet

The idea

  • You keep separate menus: Main, Sunday, Specials, Sandwiches, Desserts.
  • On Sunday, use the Sunday Roasts category (with optional description under the title, same as Sandwiches / other blocks).
  • Each one can be printed on its own (e.g. just Specials, or just Desserts).
  • On Main (or Sunday), you can also tick other menus to include on that same print sheet.

Day-to-day: Specials

  • Open Menus → tap the Specials tab.
  • Add / adjust dishes, or Upload / paste whole menu.
  • Optional: edit the short note under the Specials title (e.g. “When it’s gone, it’s gone”).
  • Tap Next · Generate → Generate menu → Print / PDF.

Include Specials, Desserts or kids on Main / Sunday

  • Open the Main menu or Sunday tab.
  • On the first step (Dishes), find Also put on this sheet.
  • Tick Specials, Desserts, Little Bells (kids), etc. as needed.
  • Generate as usual — ticked menus print on that sheet (kids in the Little Bells box).
  • Untick anytime if you only want the host menu dishes.

Clear the Main menu and upload a new one

  • Stay on the Main menu tab.
  • Tap Clear this menu → confirm (empties Main only; Specials / Desserts stay).
  • Tap Upload / paste whole menu.
  • Upload one or more PDF / Word / photos (multi-select), or paste the text → review the dishes → save.
  • Tick includes again if you want Specials / Desserts on the sheet, then Generate.

Print history

  • On the print sheet, click Save to menus to stamp a Roman version into Print history. Preview generates are not kept.
  • Use Print history at the top to reopen a sheet you saved (shared across phones / PCs).

Tip: Clear and upload only affect the tab you’re on. Specials and Desserts are separate lists — clearing Main does not wipe them.
